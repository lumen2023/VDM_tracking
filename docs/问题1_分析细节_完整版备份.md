# 问题 1：为什么车辆速度越快，路径跟踪的难度通常越大

> 实验平台：`VDM_tracking`（kinematic bicycle model，定步长 Euler，`dt = 0.1 s`）
> 被控车辆：`student_car`（轴距 `L = 2.50 m`，`lf = lr = 1.25 m`，
> 最大前轮转角 `±35° = ±0.6109 rad`，最大转角速率 `45°/s`）
> 参考路径：`circle` 路线，半径 `R = 12.0 m`，曲率 `κ = 1/12 = 0.083333 1/m`
> 速度档：`low = 3.0`、`medium = 5.0`、`high = 7.0 m/s`
> 控制器：Pure Pursuit / LQR（kinematic）/ MPC，均为本仓库 `vdm_lab/student/` 下的学生实现

---

## 0 结论摘要

本文用 **理论推导 + 9 组仿真 + 13 点受控实验** 回答"为什么速度越快越难"，主要结论：

1. **速度的直接代价是法向加速度按平方增长。** 恒曲率下 `a_n = v²κ`，速度从 3 m/s 提到 7 m/s，
   转弯所需的向心加速度从 `0.75` 涨到 `4.08 m/s²`（×5.44）。三套算法在稳态段实测的 `a_n`
   与 `v²κ` 的理论相对误差都在 **0.00%～3.42%** 以内，理论得到严格验证。

2. **转向执行器的负担不随速度增长。** 稳态转角只由曲率决定（`δ ≈ atan(Lκ) = 0.2054 rad`），
   实测在 3 档速度下几乎不变（0.192～0.215 rad）。**问题不出在"转向不够用"**——PP 在高速下
   最大转角仅 `0.2293 rad`，只用到 `±0.6109 rad` 限幅的 38%。LQR（kinematic）在 7 m/s 时
   确实冲到 `0.6109 rad` 顶死限幅并出现逐拍交替振荡，但 §5.4 的排查证明
   **这是仿真平台不执行 `max_steer_rate` 造成的伪现象**，加上真实速率限制后即消失。

3. **横向误差随速度增大的直接机理是"内切量正比于 `Lf·β`"。** PP 的几何转角公式是在**无侧偏**
   的单轮模型下推出来的，而仿真的运动学自行车模型让被跟踪点沿 `ψ+β` 方向运动，二者不一致
   产生一个指向弯道内侧的稳态偏置。13 点受控实验给出

   ```
   corner_cut ≈ 0.9302 ·(Lf · β) − 0.0280 m      R² = 0.99881，最大残差 0.0227 m
   ```

   因为前视距离 `Lf = L0 + k·v` 随速度线性增长，**速度透过前视距离把内切量线性放大**——
   这就是"速度越快，跟踪难度越大"在 PP 上最具体的一条因果链。

4. **"平均误差"会骗人，必须区分稳态误差与瞬态误差。** 全程平均横向误差随速度**不增反降**
   （PP：0.2859 → 0.2750 m；LQR kinematic：0.2195 → 0.1900 m），而稳态圆弧段误差和
   全程最大误差都在增长。原因见 §5.3。

5. **三算法精度排序：MPC > LQR kinematic > PP**，高速下差距最大
   （稳态误差 0.2987 / 0.3292 / 0.4790 m）。平滑性上 `J_delta` = PP 0.112 < MPC 1.257
   < LQR kinematic 5.493，但 LQR 那个数字里有很大一部分是平台缺陷（见 §5.4①）。

6. **发现仿真平台的两个缺陷**（都影响了本实验的读数，建议修复）：
   ① `limit_command()` 只限幅转角大小，**从不施加 `max_steer_rate`**；
   ② 终点接近限速用的是**欧氏直线距离**而非沿路径剩余弧长，对闭环路线会误触发减速。

## 1 理论分析

### 1.1 运动学自行车模型

车辆状态取 `(x, y, v, ψ)`，前轮转角 `δ`，轴距 `L = lf + lr`。后轴中心处的车身侧偏角

```
β = atan( lr · tanδ / L )
```

横摆角速度与速度的关系

```
ψ̇ = v / L · tanδ · cosβ
```

被跟踪点（后轴中心）的运动

```
ẋ = v · cos(ψ + β)
ẏ = v · sin(ψ + β)
```

注意两个要点：

- **运动方向是 `ψ + β`，不是 `ψ`。** 只要 `δ ≠ 0` 就有 `β ≠ 0`，车头指向与运动方向不一致。
  1.2 节会看到，正是这一点导致 Pure Pursuit 产生稳态内切。
- 这里的 `β` 是**运动学**侧偏角（几何量），不是轮胎侧偏角，也不含轮胎力——本仿真全程
  使用运动学模型，没有侧滑动力学。

### 1.2 稳态圆周运动关系

车辆以恒定速度 `v` 沿半径 `R` 的圆行驶时，`κ = 1/R`，稳态条件为

```
ψ̇ = v·κ                （横摆角速度）
a_n = v²·κ = v²/R       （法向/向心加速度）
δ ≈ atan(L·κ)           （所需前轮转角，小角下 ≈ L·κ）
```

由运动学模型反推 `δ`：稳态时 `ψ̇ = v/R`，代入 `ψ̇ = v/L·tanδ·cosβ` 得
`tanδ·cosβ = L/R`。当 `lf = lr` 时 `β = δ/2`，`cosβ ≈ 1 − δ²/8`，`δ ≈ 0.2054 rad` 时
`cosβ` 相对误差仅 `0.53%`，所以 `δ ≈ atan(L·κ)` 的近似足够准。

**关键观察：`δ` 与 `v` 无关，`ψ̇` 与 `v` 成正比，`a_n` 与 `v²` 成正比。**
下表给出本实验三档速度的理论值（`R = 12 m, L = 2.5 m`）：

| 速度档 | v / m/s | 理论转角 δ / rad | 理论横摆角速度 ψ̇ / rad/s | 理论法向加速度 a_n / m/s² |
| --- | ---: | ---: | ---: | ---: |
| low | 3.0 | 0.20540 | 0.25000 | 0.75000 |
| medium | 5.0 | 0.20540 | 0.41667 | 2.08333 |
| high | 7.0 | 0.20540 | 0.58333 | 4.08333 |

### 1.3 速度使跟踪变难的四条机理

把"难度"拆成可测量的四项，并给出各自的理论预期：

**机理 ①：执行器裕度被平方级地吃掉（`a_n = v²κ`）。**
跟踪弯道需要的侧向加速度随 `v²` 增长，而轮胎能提供的侧向力上限是固定的。运动学模型
里看不到这一点，但在真实车辆上它意味着 7 m/s 时轮胎已经接近附着极限。本仿真中它以
`max_normal_acceleration_mps2` 的形式被记录下来。

**机理 ②：同样的航向偏差在高速下产生更大的横向漂移速率。**
横向误差动力学近似为 `ė_y ≈ v · sin(e_ψ) ≈ v · e_ψ`。速度翻倍，**同样的航向误差导致的
横向误差增长速率也翻倍**。控制器必须在更短的时间内把航向误差压下去，否则误差会以两倍
速率积累。

**机理 ③：单位路程内的修正机会变少。**
仿真步长固定 `dt = 0.1 s`。速度 3 m/s 时每步前进 0.3 m，7 m/s 时每步前进 0.7 m。
对同一个转弯，高速下可用控制拍数按 `1/v` 减少，留给纠偏的迭代次数被压缩。

> 这条机理符合直觉，但**本实验没有把它单独验证出来**：三算法的高速稳态误差确实都
> 高于低速（精度随速度下降），但 §5.4 排查后确认没有任何一组实验出现真正的闭环失稳。
> 把"每拍前进更远"列为难度来源是合理的，但它的效应在本实验中被其他因素掩盖了。

**机理 ④（PP 特有）：前视距离随速度增大，而内切量正比于前视距离。**
`Lf = L0 + k·v`。§4 的受控实验证明 PP 的稳态内切量 `≈ Lf·β`，于是

```
e_ss(PP) ≈ 0.93 · (L0 + k·v) · β
```

速度透过 `Lf` 线性放大稳态误差。**注意这里不是 `Lf²κ/8`**——见 §4.5 的说明。

### 1.4 复杂度小结

| 量 | 随速度的标度 | 本实验 low→high 实测倍数 |
| --- | --- | --- |
| 稳态前轮转角 `δ` | `v⁰`（不变） | ≈ 1.01（PP 0.2126→0.2149） |
| 横摆角速度 `ψ̇` | `v¹` | 2.05（PP 0.2575→0.5270） |
| 法向加速度 `a_n` | `v²` | 4.23（PP 0.750→3.172） |
| PP 稳态内切 `e_ss` | `v¹`（经 `Lf`） | 1.10（PP 0.4369→0.4790） |

## 4 横向误差随速度增大的机理（受控实验归因）

§3 表 2 里有一个必须解释的数字：**PP 在 3 m/s 时稳态内切就用掉了 0.4369 m，而理论稳态
转角只有 0.2054 rad，转向远未饱和。这个 0.44 m 是从哪来的？**

### 4.1 先把"内切"确认成几何事实

用最小二乘（Kasa 代数法）对稳态段的车辆轨迹拟合圆，得到圆心与半径：

| 速度档 | 拟合圆心 / m | 参考半径 R / m | 车辆实际半径 r / m | 内切量 `R − r` / m | 实测横向误差均值 / m | 二者之差 |
| --- | --- | ---: | ---: | ---: | ---: | ---: |

三档速度下拟合圆心都落在 `(16, 12)` 附近（偏差 < 1.5 cm），**车辆确实跑在一个与参考

**这个结论对三个算法都成立。** 把同样的拟合跑遍全部 9 组（`table4_vehicle_circle_fit.csv`）：

**三者都是稳态同心偏心圆，只是偏心量不同：MPC < LQR kinematic < PP。**
（LQR kinematic 高速那行的 10.52 mm 偏差和偏移的拟合圆心 `(15.9351, 11.9931)` 是它

**但"都是偏心圆"不等于"都是同一个原因造成的"。** 下面用受控实验把 PP 那份偏心的来源
单独摘出来。

### 4.3 回归结论

用 A、B 两组共 13 个 `ds = 0.05` 的点做回归：

```

R² = 0.99881        最大残差 = 0.0227 m
数据范围：Lf ∈ [1.55, 15.05] m，β ∈ [0.000, 0.221] rad
```

拟合系数 `0.9302 ≈ 1`。**即：Pure Pursuit 在恒曲率路径上的稳态内切量约等于 `Lf·β`。**

（若把 C 组的 6 个点也混进来，`R²` 掉到 0.9637、最大残差 0.2480 m——这恰好从反面证明
`ds` 是一个**独立的、可加的**第二项，不能用一个 `Lf·β` 项解释全部数据。）

### 4.4 为什么是 `Lf·β`

Pure Pursuit 的转角公式 `δ = atan(2L·sinα / Lf)` 是从**无侧偏的单轮模型**推出来的：
它假设车辆当前位置到前视点的弦对应一段圆弧，车辆沿弦的**切线方向**运动。

但仿真的运动学自行车模型让后轴中心沿 `ψ + β` 方向运动（§1.1）。当 `β ≠ 0` 且 `Lf` 有限时，
"PP 认为车辆会走的圆"与"车辆实际走的圆"不再重合，二者的半径差就是 §4.3 拟合出来的

```
ΔR ≈ 0.93 · Lf · β
```

> 说明：这个比例关系是**从数据里拟合出来的**（13 点，`R² = 0.99881`），不是我先解析推导
> 再验证的。B 组 `β = 0` 的对照实验（内切量 −0.0423 m）是它最有力的佐证。

直观理解：前视点相对车辆车头方向偏了 `α`，而车辆的**速度方向**相对车头又偏了 `β`。PP 认为
"沿着 `α` 走就能到前视点"，实际车却是沿 `α + β` 方向在走，于是每个控制周期都向内多拐了
一点；这个偏差被前视距离放大，稳态时表现为整条轨迹向内平移 `≈ Lf·β`。

**速度如何进入这条链条：**

```
v ↑  →  Lf = L0 + 0.35·v ↑  →  corner_cut ≈ 0.93·Lf·β ↑  →  稳态横向误差 ↑
```

`β` 本身几乎不随速度变化（表 2 实测 0.1176 / 0.1229 / 0.1162，三档基本持平），
所以内切量随速度的增长**几乎完全由 `Lf` 承担**。

把这条公式外推到表 2 的三组实际运行（`Lf = 3.0 + 0.35v`，`β` 由表 1 的稳态平均转角反算，
`ds = 0.5 m` 需另加 §4.2 C 组测得的离散化修正 `+0.0595 m`）：

| 速度档 | v / m/s | Lf / m | β / rad | 预测（ds=0.05）/ m | 加 ds 修正 / m | 实测内切 / m | 偏差 / m |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| low | 3.000 | 4.050 | 0.10750 | 0.3770 | 0.4365 | 0.4369 | **+0.0004** |
| medium | 4.794 | 4.678 | 0.10855 | 0.4443 | 0.5038 | 0.4724 | −0.0314 |
| high | 6.070 | 5.124 | 0.10872 | 0.4903 | 0.5497 | 0.4789 | −0.0708 |

**低速外推吻合到 0.4 mm**，但中高速预测偏高 3～7 cm。偏差随速度增大，原因有二：

1. **`ds` 修正项只在低速单点标定过。** 上表的 `+0.0595 m` 是在 `v = 3 m/s, β = 0.1075`
   下测的，不能假定它在高速下同样大小——公式主项本身随速度线性增长，修正项未必。
2. **闭环反馈在高速下补偿得更多。** `Lf·β` 只是开环几何偏差；实际控制器每个周期都会
   对已有误差做出反应，速度越高、每拍走的距离越长，这种反馈补偿的相对作用越强。

**所以这条公式的可靠适用范围是"固定 `ds` 的受控比较"（即 §4.3 的 13 点回归），
而不是直接预测生产运行的绝对误差。** 它的价值在于揭示 `e_ss ∝ Lf·β` 这个因果方向，
从而说明"速度 → `Lf` → 内切"这条链条成立。

### 4.5 关于一个被撤回的公式

在归因过程中，我曾先验地假设内切量满足 `e_ss ≈ Lf²κ/8`（"弦高"式几何近似）。**这个公式是错的，
不应写入报告。** 实测数据直接否定了它：

- 该式预测三档速度内切量为 0.171 / 0.235 / 0.309 m，实测是 **0.437 / 0.472 / 0.479 m**，
  低估 1.7～2.6 倍；
- 该式预测低→高增长 **1.60 倍**，实测只增长 **1.10 倍**；
- 更致命的是，该式预测内切量与 `β` **无关**，而 B 组实验里 `β = 0` 时内切量是 **−0.0423 m**。

正确的规律是 §4.3 的 `corner_cut ≈ 0.93·Lf·β`（`R² = 0.99881`）。

### 4.6 同样的机理对 LQR / MPC 是否成立

**不成立。** §4.1 的表 4 显示三个算法都有稳态偏心，但 PP 那份偏心是 `β` 驱动的几何缺陷，
LQR 和 MPC 不是——它们的转角公式里都**显式带了曲率前馈**：

- LQR kinematic：`δ = −K·e + L·κ`，前馈项 `L·κ` 让"误差为零时也能跟上路径曲率"；
- MPC：优化目标直接最小化 `z` 与 `z_ref` 的偏差，参考轨迹本身带曲率。

**判别方法**：如果是 `Lf·β` 机理，那么 `β = 0` 时偏心应当消失。§4.2 的 B 组实验证实了
这一点（`β = 0` → 内切 −0.0423 m ≈ 0）。而 LQR / MPC **不使用前视距离 `Lf`**，公式里
根本没有 `Lf` 这个量，所以这条因果链在它们身上不成立。

它们残余的稳态偏心（LQR k 约 0.33～0.38 m，MPC 约 0.22～0.30 m）来自别的环节——
LQR 是误差模型在线性化点附近的近似误差与离散化误差，MPC 是有限时域（`T = 8`）
与 `Q/R` 权重折中的稳态代价。**三者偏心量的排序（MPC 0.2168 < LQR k 0.3243 < PP 0.4357，
低速档）正好与"控制器里对曲率的显式建模程度"一致**：MPC 把曲率写进了优化目标，
LQR 把它写成了前馈项，PP 则完全没有——只能靠反馈亡羊补牢。

**但要注意一个容易误读的地方：按相对增长率排，PP 反而最"稳"。** 低速→高速，内切量的
相对增长是 PP +10.6%、LQR k −1.7%、MPC +37.8%。**MPC 的相对增长率最高，却始终是最准的**
（0.2168 → 0.2988 m，绝对值仍小于 PP 的低速值 0.4357 m）。

原因是 PP 的 `Lf` 机理本身是**线性**的：`Lf` 从 4.05 涨到 5.12（+26.5%），但 `β` 基本不变，
且闭环反馈在高速度段补偿掉了一部分，所以净增长被压到 10.6%。**评价跟踪质量要看绝对误差，
不能只看增长率。**

## 5 分析问题逐条回答（对应任务文档 §2.6）

### 5.1 法向加速度是否近似随速度平方增长？偏离理论值的原因？

**是，而且验证得非常干净。** 表 3 中 `a_n` 的仿真值与 `v²κ` 理论值的相对误差：
PP 0.00/0.41/3.29%，LQR k 0.00/0.44/3.42%，MPC 0.00/0.00/0.00%。图 2 左图三线贴合理论线。

偏离的来源是**统计口径而非模型误差**：

1. 理论值用稳态段的**平均**速度 `v̄` 计算 `v̄²κ`，而 `v²` 对 `v` 是凸函数，
   `mean(v²) ≥ mean(v)²`。段内速度波动越大，仿真值越系统性偏高。
2. PP 与 LQR k 在高速档的稳态段里混入了速度下凹段（见 §5.4），波动最大，因此
   `a_n` 偏差也最大（3.29% / 3.42%）；MPC 高速段速度平稳，偏差为 0.00%。
3. 实测 `max_normal_acceleration_mps2` 在高速档为 **4.082 / 4.082 / 4.066 m/s²**
   （PP / LQR k / MPC），而 `7.0²/12 = 4.0833`——三者都达到理论值的 99.6% 以上，
   说明车辆在某一时刻确实以接近 7.0 m/s 走完了 `κ = 1/12` 的圆弧，瞬时值精确符合理论。

### 5.2 为什么理论稳态转角随速度近似不变，实际横向误差却随速度增大？

**因为"转角正确"和"轨迹正确"是两件事。**

- **转角为什么不变：** 由 §1.2，`δ ≈ atan(Lκ)` 只依赖 `L` 和 `κ`，与 `v` 无关。
  实测三档 PP 转角 0.21258 / 0.21460 / 0.21493 rad，变化 < 1.2%，理论得到验证。
- **误差为什么增大：** 转角对，但**车辆的响应方向**错了。§4 证明了横向误差由 `Lf·β` 主导，
  而 `Lf = L0 + 0.35v` 随速度线性增长，于是速度透过前视距离线性放大稳态偏置。
  同时 §1.3 机理 ② 指出 `ė_y ≈ v·e_ψ`——高速下同样的航向误差积累横向误差更快。

**一句话：速度并不改变"要拐多少度"，它改变的是"这个度数换算成多快的横向漂移、
以及控制器看得多远"。** 前者是稳态几何，不变；后者是动态过程，随速度恶化。

### 5.3 瞬态最大误差 vs 稳态误差，问题主要来自哪个阶段？

**结论：几乎全部来自稳态段，瞬态贡献可以忽略。**

用"全程最大误差"与"稳态段最大误差"相减，得到圆弧段之外的瞬态额外贡献：

| 算法 | 速度档 | 全程最大误差 / m | 稳态最大误差 / m | 瞬态额外量 / m | 占全程比例 |
| --- | --- | ---: | ---: | ---: | ---: |
| PP | low | 0.4462 | 0.4462 | 0.0000 | 0% |
| PP | medium | 0.5046 | 0.5046 | 0.0000 | 0% |
| PP | high | 0.5251 | 0.5251 | 0.0000 | 0% |
| LQR k | low | 0.3419 | 0.3419 | 0.0000 | 0% |
| LQR k | medium | 0.4130 | 0.4130 | 0.0000 | 0% |
| LQR k | high | 0.4761 | 0.4761 | 0.0000 | 0% |
| MPC | low | 0.2260 | 0.2260 | 0.0000 | 0% |
| MPC | medium | 0.2541 | 0.2541 | 0.0000 | 0% |
| MPC | high | 0.3475 | 0.3385 | 0.0090 | 2.6% |

**全程最大误差就发生在稳态圆弧段内**（九组中有八组的两者完全相等）。也就是说，
最大误差不是"切入圆弧时冲出去的瞬态尖峰"，而是**稳态偏置本身**。看图 4 右上的误差曲线
可以确认：曲线在进入圆弧后迅速升到平台值并**一直平在那里**，没有冲高回落的尖峰。

唯一例外是 MPC 高速：它的误差峰值出现在**第 144 拍（t = 14.3 s）**，即刚驶出圆弧后的
过渡段（圆弧段到第 134 拍结束），比稳态最大高 `0.00899 m`（2.6%）。因为它速度最快
（6.95 m/s），出弯时从"带曲率的稳态"切回直线的过渡最剧烈。

**这也解释了 §0 结论 4 的悖论**：为什么"全程平均误差"随速度不增反降？

> 因为分母变了。速度越高，整条轨迹里**花了更少的时间在圆弧段、占了更多采样点在直线段**
> （PP：低速稳态 215 拍 / 全程 372 拍 = 58%；高速 89 拍 / 208 拍 = 43%），
> 而直线段误差恒为 0。全程平均被直线段的零误差样本稀释，
> 速度越快稀释得越厉害，所以平均值反而下降。
>
> **这是一个统计口径陷阱：全程平均横向误差不能用来判断跟踪难度。**

### 5.4 高速时是否出现转角饱和、振荡、相位滞后、速度未达目标或未到终点？

逐项核对（九组全部 `reached_goal = True`，**没有未到达终点**）：

| 检查项 | PP | LQR kinematic | MPC |
| --- | --- | --- | --- |

| 振荡（看 `J_delta` 与误差标准差） | 否，0.112 / σ=0.013 | **是，5.493（中速的 10.9 倍）/ σ=0.0701** † | 轻度，1.257 |
| 相位滞后（`max_yaw_rate` vs 理论 0.58333） | 否，0.636（+9%） | **是，1.850（+217%）** | 否，0.865（+48%） |
| 速度未达目标 7.0 m/s | **是，6.070（−13.3%）** | **是，6.060（−13.4%）** | 否，6.952（−0.7%） |
| 未到达终点 | 否 | 否 | 否 |

**① LQR（kinematic）高速振荡是最值得写的现象。** 图 5 显示转角在 `±0.6 rad` 上等幅振荡，
`β` 同步振荡到 `0.33677 rad = 19.3°`，横摆角速度瞬时冲到 `1.850 rad/s`
（`ψ̇ = vκ = 0.5833` 的 3.17 倍）。

这个现象的归因过程值得一提，因为它**推翻了一个看起来很自然的解释**。逐条排查：

| 假设 | 检验方法 | 结论 |
| --- | --- | --- |
| 线性化模型失稳（极点越出单位圆） | 算 `eig(A − BK)`，`v = 3…8 m/s` | **否定**：`max\|λ\| = 0.844 (v=3) → 0.706 (v=7)`，最快的极点在 7 m/s 反而更靠内 |
| 上一拍转角构成代数回路发散 | 回路增益 `K₃·v/L` | **否定**：`v = 7` 时仅 `0.655 < 1`，临界速度约 `10.7 m/s` |
| 参考点重采样混叠（7 m/s 每拍走 0.7 m > `ds = 0.5 m`） | 把 `ds` 从 0.5 扫到 0.05 | **否定**：`J_delta` 仍有 3.4～5.6，振荡不消失 |

**真正的线索在原始数据里**：圆弧段 91 拍中有 **58 拍转角符号翻转**，
逐拍 `\|Δsteer\|` 最大到 `0.9 rad` —— 折合 **9 rad/s**，
而车辆声明的 `max_steer_rate = 45°/s = 0.7854 rad/s`。**这个速率超标了 11 倍。**

查 `vdm_lab/common/vehicle.py` 的 `limit_command()`：

```python
def limit_command(command, vehicle_config):
    ...
    steer = clamp(command.steer, -vehicle_config.max_steer, vehicle_config.max_steer)
```

它**只限幅转角大小，从不施加 `max_steer_rate`**。所以控制器可以命令转角在相邻两拍之间
从 `+0.61` 跳到 `−0.32`（实测值）——真实执行器不可能做到。

**决定性验证**：在控制器输出上加一层真实的转角速率限制后再跑同一组实验：

| 速度档 | `J_delta` 原始 → 加速率限 | `max_steer` 原始 → 加速率限 | 稳态 `σ(e)` | 稳态 `max\|e\|` |
| --- | --- | --- | --- | --- |
| medium | 0.5035 → **0.1087** | 0.3514 → 0.2909 | 0.0196 → 0.0183 | 0.4130 → 0.4063 |
| high | 5.4927 → **0.4702** | 0.6109 → **0.3142**（不再饱和） | 0.0701 → 0.0425 | 0.4761 → 0.4845 |

**高速档 `J_delta` 降到原来的 1/11.7，转角不再顶死限幅，而精度几乎不变**
（`max|e|` 0.4761 → 0.4845）。

**结论：LQR kinematic 的高速"振荡"主要是测试环境不执行转角速率限制造成的伪现象。**
控制器每拍都在命令一个物理上不可能的转角跳变，这个跳变又通过 `e_yaw_dot` 里的
`previous_control.steer` 反馈回下一拍的解，形成逐拍正负交替并逐步发散的极限环。
一旦执行器速率被真实约束，这个回路就被切断。

> 这不代表 LQR 在高速下没有真问题——它的精度确实随速度下降（§5.5），
> 但"高速振荡"这个具体现象应当归因于仿真平台，而不是算法本身。
> 代码注释里"同一组 `K` 在不同车速下闭环效果不同"的说法在**精度**上成立，
> 在**稳定性**上不成立（极点始终在单位圆内）。

**② PP / LQR 高速的"速度未达目标"是测试平台的接口差异，不是跟踪算法的锅。**
二者的速度控制都走 `speed_pid`，该函数含一个**终点接近限速**：

```python
if distance_to_goal < 14.0:
    target_speed = min(target_speed, (2.0 * 0.9 * distance_to_goal) ** 0.5)
```

这里的 `distance_to_goal` 是**车辆到参考路径终点的直线距离**。`circle` 路线是一条首尾相接
的闭环（终点 `(32, 0)`，回到 (16,0)–(32,0) 的驶出直线），车辆绕圈时会**从终点附近经过**：

```
实测：PP 高速稳态段 89 拍中有 23 拍到终点直线距离 < 14 m（最近 8.52 m）
      触发限速 v ≤ sqrt(1.8 × 8.52) = 3.92 m/s，实测最低跌到 4.247 m/s
      低速档因为目标速度 3.0 本来就低于限速值，所以完全不受影响
```

所以在高速下，车辆在圆弧中段会被**误判为"快到终点"而意外减速**，图上表现为
t ≈ 7 s 处速度从 6.8 掉到 4.3 再爬回 7.0（图 4 右下、图 5 左下）。
MPC 的速度在 QP 里直接跟踪参考速度、不经过 `speed_pid`，所以不受影响，达到 6.952 m/s。

**这是一个应当写进报告的测试环境缺陷**：终点限速用的是欧氏直线距离，对闭环/折返路线会
误触发。修法是改用**沿路径的剩余弧长** `s_total − s_vehicle`。

**③ 本节发现的两个平台缺陷汇总**（† 见上表）：

| # | 位置 | 问题 | 影响 | 建议修法 |
| --- | --- | --- | --- | --- |
| 1 | `vdm_lab/common/vehicle.py` `limit_command()` | 只 `clamp` 转角**大小**，从不施加 `max_steer_rate` | 控制器可命令 9 rad/s 的转角跳变（限值 0.7854）；LQR 高速因此出现伪振荡 | 在 `limit_command` 里加上 `clamp(steer, prev ± max_steer_rate·dt)` |
| 2 | `vdm_lab/common/vehicle.py` `speed_pid()` | 终点接近限速用**欧氏直线距离** | `circle` 这类闭环路线在圆弧中段被误判"快到终点"而减速（PP/LQR 高速稳态速度只有 6.07 / 6.06，目标 7.0） | 改用沿路径剩余弧长 `s_total − s_vehicle` |

**这两条都不影响本文关于"速度—难度"的主要结论**（`a_n = v²κ` 的验证、`Lf·β` 内切机理、
精度排序），因为那些结论建立在稳态几何量上；但缺陷 1 会显著污染 `J_delta` 这类平滑性指标，
缺陷 2 会污染高速档的稳态速度读数。**引用表 2 的高速 `J_delta` 与稳态速度时需要注意。**

### 5.5 三个算法中哪个高速精度和平滑性最好？

**精度：MPC 最好，LQR kinematic 次之，PP 最差。** 高速档稳态横向误差
`0.2987 / 0.3292 / 0.4790 m`（MPC / LQR k / PP），MPC 比 PP 好 38%；全程平均
`0.1679 / 0.1900 / 0.2750 m`，MPC 比 PP 好 39%。三档速度下这个排序完全一致。

**平滑性需要换一个更可靠的指标。** 表 2 的 `J_delta`（全程平均转角变化率）高速档为
`0.1122 / 1.2574 / 5.4927`（PP / MPC / LQR k），但这个指标受 §5.4 缺陷 1 污染严重，
不能直接下结论。改用**每拍转角跳变是否超过执行器速率上限**（`0.7854 × 0.1 = 0.0785 rad`）来量：

| 算法 | `max\|Δsteer\|` / rad | 超出速率上限的拍数 | 占比 |
| --- | ---: | ---: | ---: |
| PP | 0.0328 | 0 / 207 | **0.0%** |
| MPC | 0.1735 | 87 / 195 | 44.6% |
| LQR kinematic | 1.2217 | 126 / 211 | 59.7% |

- **PP 完全满足执行器速率约束（0% 越界）**，因为它的转角是前视点的**纯几何函数**，
  前视点连续移动，没有任何振荡激励源。代价是精度（§5.5 上半部分）。
- **MPC 有 44.6% 的拍越界**，虽然幅度小（`max 0.1735 rad`）。原因是我的 QP 里速率约束
  写成 `|u[1,t+1] − u[1,t]| ≤ rate·dt`，**只约束时域内部的相邻控制量，没有约束 `u[1,0]`
  相对上一拍已执行指令的跳变**。这是一个可以修的实现细节。
- **LQR kinematic 越界 59.7%，幅度最大（1.2217 rad）**，即 §5.4① 的伪振荡。

**修正后的平滑性结论：PP 最平滑（且唯一真正满足执行器约束）；MPC 与 LQR 都需要补上
转角速率限制才能给出有意义的比较。** 表 2 的 `J_delta` 列在高速档不可作为平滑性依据。

**关于"是否与任务 1 的其他路线一致"——本报告没有数据支撑，不做断言。**
本次分析的 9 组实验只覆盖了 `circle` 一条路线；`double_lane_change`、`right_angle`、
`s_curve`、`mixed_course` 未运行。要回答这个问题需要补跑这些路线的三算法对比
（见附录 B）。

## 6 结论

**速度越快，路径跟踪越难，由三条互相独立的因果链共同造成：**

1. **平方级的动力学代价** —— `a_n = v²κ`。速度翻倍，转弯需要的侧向加速度变为 4 倍
   （实测 0.750 → 3.172 m/s²，×4.23，理论验证误差 ≤ 3.42%）。这是物理层面的硬约束。

2. **线性级的几何代价** —— 稳态内切量 `≈ 0.93·Lf·β`（`R² = 0.99881`）。
   因为 PP 的转角公式建立在无侧偏假设上，而车辆实际沿 `ψ+β` 运动。由于
   `Lf = L0 + k·v`，速度线性放大这个偏置。**这是本文最具体的"速度—难度"定量关系。**

3. **单位路程内可用的修正次数按 `1/v` 减少** —— 控制周期固定 `dt`，高速下每拍前进距离
   按 `v` 增长，同一个弯道可用的控制拍数变少，抗扰与纠偏的机会被压缩。这条在数据上
   体现为**精度随速度单调下降**（三算法的高速稳态误差与最大误差都高于低速），
   但**没有**在本文可靠的范围内观察到它导致闭环失稳（见下方"被否定"第三条）。

**同时，实验否定了三个常见的想当然解释：**

- ❌ **"高速时转向不够用"** —— 稳态转角 `δ ≈ atan(Lκ)` 与速度无关，实测三档几乎不变
  （0.2126 / 0.2146 / 0.2149 rad）。PP 高速只用掉 `±35°` 限幅的 38%。
- ❌ **"误差随速度单调累积"** —— 全程平均横向误差随速度**不增反降**
  （PP 0.2859 → 0.2750 m），因为高速下车辆把更大比例的采样点留在了零误差的直线段。
  **判断跟踪难度必须用稳态圆弧段误差和最大误差，不能用全程平均。**
- ❌ **"高速下 LQR 闭环失稳"** —— 这是我在归因过程中一度采信、后来被数据推翻的判断。
  算 `eig(A−BK)` 得到 `max|λ|` 从 `v=3` 的 0.844 **降到** `v=7` 的 0.706，极点始终
  在单位圆内且裕度充足。图 5 里那个触目惊心的振荡经查证是**仿真平台不执行
  `max_steer_rate` 造成的伪现象**，加上真实速率限制后 `J_delta` 从 5.49 降到 0.47、
  转角不再饱和（§5.4①）。**固定 `K` 的跨速度裕度是够的，不需要 gain scheduling。**

**工程上的三个直接结论：**

- 前视距离不能盲目随速度增大。`Lf` 每增加 1 m，稳态内切就增加 `≈ 0.93·β` m；
  需要在 `Lf = L0 + k·v` 之外引入曲率前馈或转角偏置补偿（LQR/MPC 的实测精度优势
  正来自它们显式建模了曲率）。
- 终点接近限速必须用**沿路径剩余弧长**而非直线距离，否则闭环路线会在中段误减速。
- 仿真平台必须在执行器层施加 `max_steer_rate`，否则任何控制器的平滑性指标都不可信——
  本文的 LQR 就是被这一点冤枉的。
