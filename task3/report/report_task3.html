5.4 三算法降速对比汇总

指标PPLQR 运动学MPC
平均误差变化-25.4%-76.5%-0.7%
最大误差变化-8.7%+3.6%-10.1%

用时变化+55.4%+51.3%+52.8%
偏差位置迁移708m → 135m146m（不变）147m（不变）
分析：
1. LQR 对降速最敏感——平均误差暴降 76.5%（0.421→0.099m），因为降速直接缓解了转向饱和问题。但最大误差反升 3.6%，说明急弯处的线性化模型缺陷无法仅靠降速解决。

2. MPC 几乎不受影响——平均误差仅降 0.7%（0.0289→0.0287m），因为 MPC 本身就会主动减速，人为降低目标速度没有额外收益。终点误差反升 26.9%，可能是低速下求解器精度波动所致。

3. PP 居中——降速有 25.4% 的平均误差改善，但收益不如 LQR 明显。偏差位置从终点附近（s=708m）迁移到前段急弯（s=135m），说明降速缓解了"甩尾"但暴露了弯道瓶颈。

4. 三算法的法向加速度均大幅降低（-53% ~ -61%），说明降速对行驶平顺性的改善是普适的。

5. LQR 和 MPC 的偏差位置不变（均在 s≈146-147m），说明急弯是结构性瓶颈；PP 的偏差位置发生了迁移，说明其失效模式与速度相关。

七、仿真结果与真实通勤时间的边界说明

仿真用时（99~157 s）不能等同于真实寝室到教室的通勤时间，原因如下：

1. 无交通规则建模：仿真没有交通灯、行人、非机动车和路权让行，车辆全程无需停车等待；

2. 无真实限速与路况：仿真按固定目标速度（8 或 5 m/s）行驶，未考虑校园道路限速、拥堵、减速带和路面附着条件；

3. 无动态障碍：没有其他车辆、行人穿行等需要避让的场景，横向误差全部来自控制器本身而非避障行为；

4. 底图仅作空间背景：OSM GeoJSON 底图只提供道路几何参考，仿真并未对道路属性（车道数、单行、限速）进行建模。

因此，本实验的"用时"只能用于相同设置下不同算法、不同速度之间的相对比较（例如降速使用时增加约 51%~55%），不能作为真实通勤时间的预测。此外，运动学自行车模型假设轮胎无侧偏，结论在低速下可信，高速工况需要动力学模型进一步验证。
