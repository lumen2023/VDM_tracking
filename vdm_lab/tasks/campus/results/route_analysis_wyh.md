# 校园路线与最大偏差分析

本次沿用原有校园道路走向，局部放宽三个主要转弯及一处短距离连续转向，保持起终点不变。新路线长约879.5米，最小转弯半径约5.29米。最大曲率由0.417降至0.189米⁻¹，低于车辆的0.264米⁻¹上限，理论最大转角约25.9°，原有曲率超限问题已解决。

三种算法使用相同车辆、参考速度和0.1秒步长，均到达终点。PP、运动学LQR和MPC用时分别为299.7、300.2和299.5秒，平均绝对横向误差分别为0.0307、0.0250和0.0146米，最大误差为0.774、0.556和0.326米。全程实际转角均未触及35°上限。

三者最大偏差均位于第一弯内，分别在曲率峰值后约0.8、2.6和0.2米处，说明峰值位置还受到前视、速度响应和控制过程影响。放宽后PP与MPC最大误差下降，LQR略增，不能将几何可行性等同于所有误差指标改善。

将PP巡航上限从3降至2米/秒后，平均误差降至0.0248米，最大误差降至0.739米，但用时增加至441.8秒。路线虽满足转向几何限制，仍未验证道路宽度、障碍物和交通规则，仿真结果不能直接代表真实通勤时间或通行安全。
